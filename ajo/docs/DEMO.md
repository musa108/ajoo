# Demo script (about 2.5 minutes)

Record at 1080p. Use the local seed or a Monad testnet deployment with the **5-minute demo cycle** so a full cycle fits on camera.

| Time | Show | Say |
|---|---|---|
| 0:00 | Landing hero, the ring turning | "In Nigeria it's ajo, in Ghana susu, in Mexico tanda. Millions save this way, and it all runs on trust in one organizer." |
| 0:15 | Start a circle form, live preview | "I set the terms once: five people, five dollars, every five minutes, one payment as a safety deposit." |
| 0:30 | Submit, circle page, copy invite link | "The contract holds the money. Nobody, including me, can change these terms." |
| 0:45 | Four other wallets join, ring fills, circle starts | "When the last seat fills, the first cycle starts." |
| 1:05 | Everyone pays, click **Settle**, payout lands | Point at the transaction time. "Monad confirms in about a second, so a payout feels instant, and a five-dollar payment is worth making." |
| 1:30 | One member misses, deposit covers it, ledger shows the shield icon, score drops | "The pot stays whole. The record shows who missed." |
| 1:50 | **My record**: score and rules table | "Every payment writes to a public record the person owns. It cannot be edited, bought, or sold." |
| 2:05 | **Credit**: limit, borrow, repay | "Past 400 you can borrow against your record. Repaying raises the score." |
| 2:25 | Landing safety section | "We're upfront about the limits: unaudited, deposits don't cover everything, testnet only." |

Before recording: run the keeper, fund each demo wallet with test dollars and gas, and rehearse once. Keep a second tab on the explorer.
